# FastFiles

FastFiles 是一款 Windows 原生文件管理器，界面和功能对照 [Files](https://github.com/files-community/Files) 设计，用 C++（Win32）和 Rust 编写，启动快，占用内存少。

![主页](docs/images/home-light.png)

## 功能

- **标签页**：多个文件夹同时打开，标签可拖动排序、复制、移到新窗口，关闭后可以重新打开。
- **双窗格**：左右两个窗格并排浏览，在两个位置之间复制、移动文件更方便。
- **主页**：快速访问固定的文件夹、驱动器和网络位置。
- **侧边栏**：固定项、驱动器、库、网络、WSL、文件标签，分组可折叠。
- **多种布局**：详细信息、列表、卡片、网格、列视图和自适应布局；每个文件夹分别记住布局、排序和分组方式。
- **文件标签**：给文件和文件夹加上彩色标签，在侧边栏按标签查看。
- **搜索**：在当前文件夹及子文件夹中按文件名搜索。
- **预览窗格**：预览图片、文本、文档和音视频，显示文件详细信息。
- **状态中心**：复制、移动、删除的进度和结果集中显示。
- **Git 状态**：在 Git 仓库里显示当前分支和同步状态。
- **外观**：浅色 / 深色主题、背景颜色、背景图片、云母材质和字体都可以调整。
- **多语言**：界面支持多种语言。
- **快捷键**：快捷键可以自定义，设置可以导入和导出。
